# EconoReport

Econometrics final project materials on the relationship between the Taiwan-Japan exchange rate and Japanese tourist arrivals to Taiwan.

## Main files

- `taiwan_japan_fx_tourism_report_en.tex`: main English LaTeX report
- `taiwan_japan_fx_tourism_report_en.pdf`: compiled report
- `run_analysis.R`: reproducible regression and table-generation script
- `資料.xlsx`: cleaned estimation dataset
- `原始來源資料.xlsx`: original source workbook
- `output/`: generated regression tables and figures used by the report
- `research_log_zh.md`: Chinese work log and reality-check notes

## Data sources referenced in the report

- Taiwan Tourism Administration inbound visitor statistics
- Investing.com JPY/TWD exchange rate series
- FRED Brent crude price series (`POILBREUSDM`)
- FRED Japan industrial production series (`JPNPRINTO01IXOBM`)
