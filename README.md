# The Exchange Rate and Japanese Tourist Arrivals to Taiwan

This repository contains the materials for an econometrics final project on the relationship between the Taiwan-Japan exchange rate and Japanese tourist arrivals to Taiwan.

The project is written as a reproducible research workflow:

- the cleaned monthly dataset is stored locally,
- the regressions are generated by an R script,
- the tables and figure are exported automatically,
- and the final paper is compiled in LaTeX.

## Research Question

The central question is:

> Does the Taiwan-Japan exchange rate affect the number of Japanese tourists visiting Taiwan?

The empirical design examines whether exchange-rate movements remain important after controlling for:

- monthly seasonality through 11 month dummy variables,
- Japanese industrial production as a proxy for origin-country demand conditions,
- Brent crude oil prices as a proxy for transportation cost pressure,
- time trend and dynamic persistence in tourist arrivals.

## Sample

- Estimation frequency: monthly
- Current regression sample used in the project: `2009M10–2019M12`
- Reason for focusing on the pre-pandemic period:
  COVID-19 border restrictions broke the normal tourism-demand mechanism, so pandemic years are excluded from the baseline design.

## Repository Structure

- `資料.xlsx`
  Cleaned estimation dataset used by the regression script.

- `原始來源資料.xlsx`
  Source workbook collected from the original public databases.

- `run_analysis.R`
  Reads the dataset, estimates the models, performs diagnostic checks, and exports LaTeX tables and figure files.

- `output/`
  Generated regression tables and diagnostics, including:
  - baseline regression table,
  - robustness table,
  - Stata-like detailed OLS tables,
  - hypothesis test table,
  - diagnostic test table,
  - ADF-style spurious-regression check table,
  - correlation matrix,
  - summary statistics,
  - tourism/exchange-rate index figure.

- `taiwan_japan_fx_tourism_report_en.tex`
  Main report file that inputs the generated tables from `output/`.

## Empirical Models Included

The current workflow estimates several specifications:

1. Bivariate regression
2. Full model with controls and 11 month dummies
3. Dynamic model with lagged tourist arrivals
4. Distributed-lag exchange-rate model
5. First-difference model

The project also includes:

- joint hypothesis tests,
- Durbin-Watson tests,
- Breusch-Godfrey serial-correlation tests,
- Breusch-Pagan heteroskedasticity tests,
- RESET functional-form tests,
- ADF-style unit-root and spurious-regression checks.

## Data Sources

The report is based on the following public sources:

- Japan inbound visitor counts to Taiwan:
  [Taiwan Tourism Administration Inbound Search](https://stat.taiwan.net.tw/inboundSearch)

- JPY/TWD exchange rate:
  [Investing.com JPY/TWD](https://uk.investing.com/currencies/jpy-twd)

- Brent crude oil price:
  [FRED POILBREUSDM](https://fred.stlouisfed.org/series/POILBREUSDM)

- Japan industrial production index:
  [FRED JPNPRINTO01IXOBM](https://fred.stlouisfed.org/series/JPNPRINTO01IXOBM)

## How to Reproduce

1. Make sure R is available with the packages used in the script:
   - `readxl`
   - `dplyr`
   - `lmtest`
   - `sandwich`

2. Run:

```bash
Rscript run_analysis.R
```

3. Recompile the report:

```bash
latexmk -pdf taiwan_japan_fx_tourism_report_en.tex
```
